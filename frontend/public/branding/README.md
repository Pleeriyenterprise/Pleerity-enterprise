# Brand assets (required for launch)

Add the following files to this folder so the app displays correctly:

| File | Purpose |
|------|--------|
| **pleerity-logo.png** | Logo used in header, admin sidebar, client portal, and login pages. |
| **favicon.png** | Browser tab and bookmarks (referenced in index.html). |

See also `frontend/public/LOGO-AND-FAVICON-README.md` for full details.

If these files are missing, the build will still succeed but the deployed site will show broken logo and default favicon until assets are added (or supplied at deploy time).
